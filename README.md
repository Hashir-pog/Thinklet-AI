# Thinklet - AI Study Assistant

Thinklet is an AI-powered study assistant focused on Socratic tutoring, active recall, Feynman technique, quiz generation, and summarization.

## Features
- Chat-based study support
- Summarization and quiz generation
- Active recall and Feynman-style explanations
- Separate frontend and backend structure

## Tech Stack
- Frontend: JavaScript
- Backend: Python, FastAPI
- AI: Local/AI model integration

## How to Run
```bash
cd backend
pip install -r requirements.txt
python main.py
```

Then open the frontend folder and run the frontend according to its package setup.
